About QuickNotes

QuickNotes is a lightweight note-taking web page created as part of the Web Foundations course. It demonstrates semantic HTML structure, navigation, lists, tables, and forms - all with plain HTML and no frameworks.

How to use QuickNotes

  1. Open the Home page to see your current notes.
  2. Jot down ideas, to-dos, or reminders as list items.
  3. Send feedback using the form at the bottom of this page.

Features

  • Simple, distraction-free note taking
  • Semantic HTML5 structure with header, nav, main, and footer
  • Keyboard shortcuts for fast navigation
  • A feedback form so you can tell us what to improve
